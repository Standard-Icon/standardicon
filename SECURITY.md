# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

Use GitHub's private vulnerability reporting: open the **Security** tab of [Standard-Icon/standardicon](https://github.com/Standard-Icon/standardicon) and choose **Report a vulnerability**.

You will get a reply within a week.

## What's in scope

- The npm packages: `standardicon`, `@standardicon/react` and `@standardicon/mcp`.
- The CLI that people run through `npx standardicon`.

The CLI needs no network access and has no install scripts. A report that shows otherwise is in scope.

## Out of scope

The website and its hosting are not covered by this policy. Report those the same way and we will look at them, but they are handled separately.
